# Methodology (detailed)

The full protocol — more granular than the paper's Method section. A
replicator should be able to reproduce the study from this document alone.

## Sections to fill

1. **Research question & hypotheses** — stated precisely enough to be falsifiable.
2. **Materials** — exact prompts, question sets, model versions and access dates,
   sampling parameters (temperature, top-p, max tokens, system prompt).
3. **Procedure** — step by step: how each model was queried, in what order,
   how many trials, how randomisation/counterbalancing was handled.
4. **Measures & operationalisation** — every construct defined in operational
   terms. What exactly is measured, and how a raw transcript becomes a number.
5. **Coding scheme** — if responses are hand- or model-coded: the rubric,
   inter-rater procedure, adjudication of disagreements.
6. **Analysis plan** — the statistics/aggregations applied, pre-registered vs
   exploratory, what counts as the headline result.
7. **Deviations** — anything that changed between plan and execution, dated.

Keep this in sync with `analysis/` and `data/`.
